# Attack-Shark-Studio
Apps for edit X11 Mouse and K86 Keyboard

Dois programas para Windows que substituem o software oficial da Attack Shark:

- [K86-Studio](K86-Studio): teclado K86 (luzes, modo música, teclas, macros, imagem na telinha)
- [X11-Studio](X11-Studio): mouse X11 (DPI, luz, botões, polling rate, bateria)
- [H510-Studio](H510-Studio): headset Redragon H510 Zeus Pro, versão de teste (volume, microfone, retorno da voz)

A pasta `Shared` tem o código que os apps usam (visual e comunicação USB).

## Compilar

Não precisa instalar nada. Entre na pasta do app e rode o `build.cmd`, que usa o compilador de C# que já vem no Windows.

Não é um projeto oficial da Attack Shark nem da Redragon.
